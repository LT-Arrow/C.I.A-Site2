COMMAND FIELD GUIDE

Find your next move.

Search the main player and admin workflows. Copy a command, then select its arguments in Discord.

Rest, ready, then explore.

In a dungeon lobby, everyone marks Ready and the leader begins. Direction buttons show valid movement. Required rooms appear in the floor exit checklist. Your HP stays with you until a rest service or owned healing potion restores it.

Give your server its starting content.

Admins open /admin dungeon create to install the Arcana or C.I.A. packs. Use /admin skills expansion to enable unique signatures and expanded classes. Add personal, class and species trees with /admin skills preset.

Keep the boundaries clear.

Only administrators create and award blessings. Ordinary class purchases use earned points. Unique signatures evolve with verified character levels. City-board quests use the existing GM review process, while dungeon battle and completion rewards are automatic.
