Lore belongs to its authors.

Crossworlds is built through its community’s stories. This site preserves the supplied C.I.A. records and documents the mechanics available in the bot. New canon belongs in staff-reviewed lore—not automatically generated alerts.

Publish and edit lore as Cross.

In Discord, administrators can assign lore channels, draft entries, preview them and publish as Cross. Editing a published entry updates the same message. Use /admin lore setup, /admin lore create and /admin lore edit.

This static GitHub Pages archive is separate from the bot’s saved lore. Discord edits do not automatically update the website. Public website copy is maintained with the site source.
